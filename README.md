# The REAL Engine!
## huh?
Simple 3D game engine made with C#, OpenTK, FMOD, and bunch of other libs... See `Assets/ThirdPartyNotices.txt` for more info.

## Features
- Component system (like in unity)
- Scene editor (like in unity)
- Game console (like in ~~unity~~ source)
- Bullet phys engine (not like in unity)
- FMOD for audio
- Sample Text
