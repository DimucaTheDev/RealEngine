SaveSceneToFile(Scene, string)

Saves the provided scene to the specified path in JSON format.

public static void SaveSceneToFile(Scene scene, string path)

Parameters

scene Scene

Scene to be saved

path string

Path where save file will be created.

If path ends with .json, the file will be created at that path, otherwise a data.json will be created at specified path

Remarks

The path can be either a directory or a file path ending with .json.
If a directory is provided, the scene will be saved as data.json within that directory.

Exceptions

JsonException

Can occur if data saved via GetSaveData() can not be converted to JSON
