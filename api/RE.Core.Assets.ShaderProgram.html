Remarks

A ShaderProgram encapsulates the lifecycle of an OpenGL program object, including attaching shaders, linking them, and setting uniform values. Use this class to manage GPU shader resources and to set uniform variables for rendering. This class also provides resource cleanup when unloaded. Thread safety is not guaranteed; use from the same thread that owns the OpenGL context.

SetStructArray<T>(string, IEnumerable<T>)

Sets an array of struct values for the specified variable name, mapping each property of the struct to a corresponding uniform variable.

public void SetStructArray<T>(string varName, IEnumerable<T> values)

Parameters

varName string

The base name of the variable to which the struct array will be assigned. Each struct property will be mapped to a uniform variable using this base name.

values IEnumerable<T>

An enumerable collection of struct values to set. Each element in the collection represents a struct whose properties will be assigned to corresponding uniform variables.

Type Parameters

T

The type of the struct whose properties will be set as uniform variables. Must be a reference type with public properties.

Remarks

Each property of the struct type is mapped to a uniform variable named using the pattern "varName[i].PropertyValue", where i is the index in the array. If a property is decorated with the GlPropertyNameAttribute, its PropertyName value is used instead of the property name. Properties with null values are skipped.

SetStruct<T>(string, T)

Sets the values of all public properties of a struct as individual uniforms, using the specified variable name as the struct prefix.

public void SetStruct<T>(string varName, T value) where T : struct

Parameters

varName string

The name to use as the prefix for the struct's uniform variables.

value T

The struct instance whose public property values will be set as uniforms.

Type Parameters

T

The type of the struct whose properties will be set as uniforms. Must be a value type.

Remarks

Each public property of the struct is set as a separate uniform variable, with the uniform name composed of the provided struct name and the property name (e.g., "MyStruct.Property"). Properties with null values are ignored. Custom property and struct names may be used if the appropriate attributes are present.

SetValue<T>(string, T)

Sets the value of a uniform variable in the shader program by name.

public void SetValue<T>(string name, T value) where T : notnull

Parameters

name string

The name of the uniform variable to set. Cannot be null.

value T

The value to assign to the uniform variable. Must be of a supported type such as int, uint, float, double, bool, OpenTK.Mathematics.Vector2, OpenTK.Mathematics.Vector3, OpenTK.Mathematics.Vector4, OpenTK.Mathematics.Color4, OpenTK.Mathematics.Matrix2, OpenTK.Mathematics.Matrix3, or OpenTK.Mathematics.Matrix4.

Type Parameters

T

The type of the value to set. Must be a supported uniform type and not null.

Remarks

If the specified uniform name does not exist in the shader program, the method logs an error and does not set any value. Only certain types are supported; attempting to use an unsupported type will result in an exception.

Exceptions

NotSupportedException

Thrown if the type of T is not supported as a uniform variable.
