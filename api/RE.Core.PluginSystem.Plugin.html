Remarks

Inherit from this class to create a custom plugin. Override the OnLoad() and OnUnload() methods to define initialization and cleanup logic for your plugin. Use the Serilog.Core.Logger property to write log messages within the plugin context. The PluginInformation property should provide metadata about the plugin, such as its name and version.
